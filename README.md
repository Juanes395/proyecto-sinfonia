Sintonía — Plataforma de Streaming Musical

Aplicación web frontend desarrollada con React y Vite

## Requisitos previos

* **Node.js** (versión 18 o superior)
* **npm** (incluido con Node.js)

## Instalación y ejecución local

1. **Clonar el repositorio:**
   git clone <https://github.com/Juanes395/proyecto-sinfonia.git>

EJECUTAR COMANDOS:
- Instalar dependencias: 
npm install
- Crear un archivo .env y crear la variable:
VITE_API_URL=https://yanethm-sintonia-api.fly.dev/api/v1 
-Para visualizar ejecutar
npm run dev
